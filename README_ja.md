# Grafana 用 Attitude 3D Panel

WebGL を用いて Grafana ダッシュボード上に 3D モデルを描画するパネルです。宇宙機の姿勢監視やロボットの姿勢可視化など、リアルタイムに変化するクォータニオンを使った表示に適しています。

![探査機の3Dモデルの表示結果の例](screenshots/display.png)

## 特長

- **3D モデルを何個でも**同一シーンに配置でき、モデルごとにアセット・位置・姿勢を個別に設定可能。
- GLB / GLTF / OBJ アセットを読み込み、位置とクォータニオンをモデルごとにテレメトリへひも付け可能。
- カメラの注視対象を原点または**任意のモデル**から選択でき、対象が動けば注視点も追従。
- モデルごとの**クォータニオン内挿/外挿**により、リフレッシュ間も滑らかに動き続けます。
- 指向性ライトと環境光を組み合わせ、視認性に合わせたライティングを構築。
- モデルごとに原点・バウンディング球中心・頂点平均を切り替え、座標系の違いに柔軟に対応。

従来の単一モデル版で作成したダッシュボードは**自動的に移行**されます。[移行](#移行)を参照してください。

## インストール手順

1. 依存パッケージを `pnpm install` で取得します。
2. `pnpm build` でパネルをビルドします。
3. 生成されたフォルダを Grafana のプラグインディレクトリに配置 (開発時はシンボリックリンクも可)。
4. 必要に応じて Grafana 側で未署名プラグインを有効化します。

## 利用の流れ

- **モデルの追加**: **Objects** の *Add Model* を押します。モデルごとに設定を持ち、左のリストで選んだモデルの設定を右側で編集します。
- **モデルアセットの登録**: Grafana から到達可能な場所へ `.glb`, `.gltf`, `.obj` を配置し、URL にはテンプレート変数も利用できます。CORS の Preflight Request に応答するサーバである必要があります。
- **位置とクォータニオンの接続**: Position X/Y/Z と Quaternion X/Y/Z/W はそれぞれ独立に *Const* / *Field* を選べます。
- **中心位置の調整**: 原点・バウンディング球中心・頂点平均を切り替えてモデルの中心を合わせます。
- **カメラ調整**: 注視対象を選び、方向ベクトルと相対距離 (対象のバウンディング球半径が 1) を設定します。
- **動きの平滑化**: モデルごとに補間を有効化すると、ダッシュボードのリフレッシュ間も姿勢が進み続けます。
- **ライティング設定**: 指向性ライトと環境光の色・強度・向きを調整し、モデルの陰影を制御します。
- **ヘルパーとマウス制御**: デバッグ時はヘルパー軸を表示し、レビュー用途にはマウス制御を有効化します。

## パネルオプション

### Camera

<img src="screenshots/menu2.png" alt="Camera タブ。注視対象・方向ベクトル・距離・マウス制御のトグルが見える" width="250" />
*パネル表示: 注視対象を選び、カメラ方向を定数またはフィールドで与え、相対距離とマウス制御の可否を設定します。*

- **Target**: カメラの注視対象。`Origin (0, 0, 0)` または Objects で追加したモデルから選びます。カメラ距離は対象のバウンディング球半径を基準にスケールし、対象が動けば注視点も追従します。`Origin` の場合は、表示中の全モデルを包含する球の半径が基準になります。
- **Direction Input**: カメラ方向を定数またはデータフィールドから取得します。
- **Direction X / Y / Z**: カメラ方向ベクトルの各成分。
- **Distance**: 対象からの相対距離 (対象のバウンディング球半径を 1 とするスケール)。
- **Mouse Control**: オービットコントロールによるマウス操作を有効にします。

### Directional Light

<img src="screenshots/menu3.png" alt="Directional Light / Ambient Light / Scene の各セクション" width="250" />
*パネル表示: 指向性ライトと環境光の方向・強度・色を調整し、Scene でヘルパー軸と背景色を設定します。*

- **Direction Input**: 光源方向を定数またはフィールドから選択。
- **Direction X / Y / Z**: 指向性ライトの方向ベクトル。
- **Color / Intensity**: ライトの色と強度を設定します。

### Ambient Light

- **Color / Intensity**: 環境光の色と強度を調整します。

### Scene

- **Helper**: ヘルパー軸の表示を切り替え、ワールド座標系を確認します。
- **Background Color**: 背景色または透過背景を指定します。

### Objects

<img src="screenshots/menu1.png" alt="Objects タブ。モデル一覧と選択中モデルの設定が並ぶ" width="250" />
*パネル表示: シーンにモデルを追加し、各モデルのアセット・位置・クォータニオンを設定します。*

- **Add Model**: シーンに 3D モデルを追加します。下のリストに全モデルが並び、クリックで選択、目のアイコンで表示/非表示、矢印で並び替え、ゴミ箱アイコンで削除します。

各モデルは以下の設定を持ちます。

- **Name**: 表示名。オブジェクト一覧に表示され、*Camera → Target* の選択肢としても使われます。
- **Model URL**: GLB / GLTF / OBJ の URL またはテンプレート変数。CORS の Preflight Request に対応したサーバが必要です。
- **Center**: モデルの中心を *Origin* (原点)、バウンディング *Sphere* の中心、頂点の *Average* から指定します。
- **Scale**: モデルに適用するスケール係数。
- **Position X / Y / Z**: ワールド座標におけるモデルの位置。
- **Quaternion X / Y / Z / W**: モデルに適用する姿勢。
- **Interpolation**: [クォータニオン補間](#クォータニオン補間)を参照。

Position X/Y/Z と Quaternion X/Y/Z/W は、それぞれ独立に入力元を選べます。

- **Const**: 固定の数値を使用します。
- **Field**: クエリのフィールドの最終行の値を使用します。フィールドは `Series.Field` 形式 (例: `A.q_x`) でも、素のフィールド名 (`q_x`) でも指定できます。複数のクエリが同名のフィールドを返す場合は、`Series.Field` 形式でどのクエリのフィールドかを明示してください。

## クォータニオン補間

**モデルごと**に、**Objects** 内の各モデルの *Interpolation* で設定します。

<img src="screenshots/menu4.png" alt="Interpolation セクション。Enable / Time Field / Retained Samples / Max Extrapolation が並ぶ" width="250" />
*パネル表示: 補間を有効にすると、ダッシュボードのリフレッシュ間もモデルが回り続けます。*

Grafana はリフレッシュ単位で離散的にデータを届けるため、フィールドに直接ひも付けた姿勢は新しいデータが届いたときしか動きません。補間を有効にすると、パネルは時刻付きクォータニオンを少数だけリフレッシュをまたいで保持し、表示レンジの終端に向けて球面補間 (通常のユースケースでは**外挿**) を行うため、リフレッシュ間もモデルが滑らかに回り続けます。

- **Enable**: 機能を有効化します。既定: off。
  - Quaternion X, Y, Z, W が**すべて** *Field* のときのみ有効です。いずれかが *Const* の場合はサンプリング対象が無いため、補間は行われません。
  - 表示レンジが相対指定 (例: `now-5m` 〜 `now`) の場合、外挿の目標時刻はデータ到着からの経過時間だけ毎フレーム進みます。
- **Time Field**: 保持するクォータニオンサンプルに使う時刻フィールド。空欄にすると対象フレームの時刻フィールドを自動検出します。
- **Retained Samples**: リフレッシュをまたいで保持する時刻付きクォータニオンの数。`2` で等角速度外挿になります。既定: `2`。
- **Max Extrapolation [ms]**: 目標時刻が最新サンプルからこの時間以上離れたら外挿を打ち切ります。データが止まったときにモデルが回り続けるのを防ぎます。`0` にすると外挿を無効化し、内挿のみになります。既定: `5000`。

### 処理の流れ

**リフレッシュのたびに**、パネルはクォータニオン 4 成分をすべて含むフレームを探し、その末尾 *Retained Samples* 行を取り出して時刻値と対応付け、クォータニオンを正規化したうえで時刻順に保持します。それより古いサンプルは保持しないため、ダッシュボードを開き続けてもメモリ消費は一定です。

**毎フレーム**、パネルは目標時刻を決めて、保持中のバッファをその時刻でサンプリングします。

1. **目標時刻**: 表示レンジの終端 (`${__to}`)。レンジが相対指定 (`now` で始まるもの) の場合は、さらにデータ到着からの実時間の経過分だけ目標時刻を進めます。これによりリフレッシュ間も「現在時刻」を追い続け、直前のリフレッシュ時刻で止まりません。
2. **クランプ**: 目標時刻は `最新サンプルの時刻 + Max Extrapolation [ms]` で頭打ちにします。
3. **サンプル対の選択**: クランプ後の目標時刻が最新サンプル以降なら (通常のケース)、末尾 2 サンプルを使います。そうでなければ目標時刻を挟む 2 サンプルを使うため、保持ウィンドウ内の動きは区分的な slerp になります。
4. **Slerp**: `u = (目標時刻 - a.t) / (b.t - a.t)` として `slerp(a, b, u)` を求めます。three.js の slerp は大円公式で実装されているので、`u > 1` でも同じ大円上を同じ角速度で進み、結果は単位クォータニオンのまま保たれます。再正規化による誤差の蓄積もジンバル由来の破綻も起きません。

*Retained Samples* が既定の `2` のとき、これは最新 2 姿勢からの等角速度外挿そのものです。値を増やしても外挿がより滑らかになるわけではなく (先頭の 2 サンプルが外挿を決めるため)、目標時刻が保持ウィンドウの内側に戻ったときに正しく内挿できるようになります。

縮退ケースも設定なしで処理されます。サンプルが 1 個しかないバッファはその姿勢をそのまま適用し、時刻差が 1 ms 未満の対はゼロ割りを避けて新しい側の姿勢を適用します。

## 移行

従来の単一モデル版で作成したダッシュボードは、パネルを最初に開いたときに自動的に移行されます。旧設定の `Model URL` / `Center` / Quaternion X..W / Quaternion Interpolation は `Model 1` という 1 個のオブジェクトに変換され、位置は (0, 0, 0)、Camera Target は `Origin` に設定されるため、見た目は以前とまったく同じになります。カメラ・ライト・背景の設定はそのまま引き継がれます。
